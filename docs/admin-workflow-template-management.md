# إدارة قوالب سير العمل — الإصدار 1

## الوظيفة

تضيف هذه الحزمة صفحة إدارية مستقلة لإدارة مسارات اعتماد الاتفاقيات والمبادرات. يستطيع مسؤول النظام:

- إضافة مرحلة جديدة وحذف المراحل المخصصة.
- تحريك المرحلة لأعلى أو أسفل.
- اختيار مرحلة إلزامية أو اختيارية.
- تشغيل المرحلة بالتسلسل أو بالتوازي مع المرحلة السابقة.
- تحديد المسؤول حسب منصب أو مكتب/وحدة تنظيمية.
- اختيار نطاق ثابت، أو قسم مقدم الطلب، أو كليته، أو مستوى الجامعة.
- نشر نسخة جديدة مع سبب موثق.
- الرجوع إلى الإصدارات السابقة وفتحها كمسودة لإصدار جديد.

## حماية الطلبات المفتوحة

النشر لا يعدل نسخ المراحل الموجودة داخل الاتفاقيات والمبادرات المفتوحة. كل طلب جديد يأخذ Snapshot من القالب النشط عند دخوله مسار الاعتماد.

## المراحل المتوازية

اختيار «متوازية» يجعل المرحلة ضمن مجموعة تنفيذ المرحلة السابقة. لا ينتقل المسار إلى المجموعة التالية حتى تنتهي جميع المراحل النشطة في المجموعة الحالية.

## المراحل الاختيارية

- في الاتفاقيات، يستطيع صاحب آخر قرار قبل المجموعة التالية تحديد المراحل الاختيارية المراد إدخالها.
- في المبادرات، تعمل المرحلة الاختيارية عندما يتوفر مسؤول مؤهل، ويتم تخطيها تلقائيًا عند عدم توفر مسؤول.

## المسؤولية

- **حسب المنصب:** يجب أن يملك المستخدم المنصب المحدد والصلاحية المناسبة.
- **حسب المكتب أو الوحدة:** يختار النظام مستخدمًا فعالًا في الوحدة يملك صلاحية الاعتماد.
- **قسم مقدم الطلب / كلية مقدم الطلب:** يحل النظام الوحدة تلقائيًا من التسلسل التنظيمي.

## التثبيت

1. فك ضغط الحزمة داخل جذر المشروع.
2. شغّل `php .\apply_admin_workflow_template_management_v1.php`.
3. بعد نجاح التثبيت شغّل `database-manager.cmd` واختر الخيار 2.
4. اختبر الصفحة `uob-agreements/workspace/admin-workflows.php`.
