# إدارة المستخدمين والصلاحيات

## الهدف

توفر صفحة **إدارة المستخدمين** للمستخدم الذي يملك صلاحية `MANAGE_USERS` مكانًا واحدًا لإدارة هوية المستخدم، حالة الحساب، صلاحية إنشاء الاتفاقيات والمبادرات، أدوار الاعتماد، والمنصب والوحدة التنظيمية.

## النموذج المعتمد

لا ينشئ التحديث جداول منفصلة للمكاتب أو الكليات أو الأقسام. يعتمد على الجداول الموجودة:

- `organizational_units`: الهيكل الهرمي للجامعة والمكاتب والكليات والأقسام.
- `positions` و`user_positions`: المنصب الحالي وسجل التنقلات السابقة.
- `roles` و`permissions` و`role_permissions` و`user_roles`: الصلاحيات والأدوار.
- `audit_logs`: توثيق تغييرات الإدارة مع السبب وهوية المنفذ.

## التحكم في الإنشاء

- دور `Agreement Creator` يمنح `CREATE_AGREEMENT` والصلاحيات اللازمة للتعديل والإرسال والعرض.
- دور `Initiative Creator` يمنح `CREATE_INITIATIVE` والصلاحيات اللازمة للمبادرة.
- يمكن منح أحد الدورين أو كليهما أو عدم منحهما.
- فحص الإنشاء في الخادم يعتمد على الصلاحية الفعلية، وليس على اسم المنصب وحده.

## أدوار سير العمل

- `Agreement Approver`: يسمح بتنفيذ خطوات الاتفاقيات المسندة للمستخدم ضمن وحدته التنظيمية.
- `Initiative Approver`: يسمح بتنفيذ خطوات المبادرات المسندة حسب الهيكل التنظيمي.
- المنصب والوحدة يحددان **أين** يتم توجيه الطلب، والدور يحدد **ما الإجراء المسموح**.

## النقل التنظيمي

عند تغيير المنصب أو الوحدة:

1. يُغلق التكليف النشط السابق بدل حذفه.
2. يُنشأ تكليف جديد بتاريخ السريان.
3. يبقى السجل السابق ظاهرًا في تبويب السجل التنظيمي.
4. يمنع الخادم التركيبات غير الصحيحة، مثل تعيين الرئيس خارج مكتب الرئيس أو العميد خارج كلية.
5. يمنع وجود شاغلين نشطين لمنصب فريد في الوحدة نفسها.

## الحماية

- كل مسارات API محمية بصلاحية `MANAGE_USERS` من جهة الخادم.
- لا يستطيع المسؤول تعطيل حسابه بنفسه أو إزالة صلاحية إدارة المستخدمين من نفسه.
- لا يمكن إزالة آخر مسؤول نشط يملك `MANAGE_USERS`.
- الحفظ يستخدم `updated_at` لمنع الكتابة فوق تعديل مسؤول آخر.
- سبب التغيير إلزامي ويُحفظ في `audit_logs`.
- لا تُرسل قيم Boolean إلى PostgreSQL كسلاسل فارغة.

## التثبيت

بعد سحب فرع `FatemaE`، شغّل مدير قاعدة البيانات واختر تثبيت/إصلاح قاعدة البيانات لتطبيق:

`20260805_004500_admin_user_management.sql`

ثم افتح:

`uob-agreements/workspace/admin-users.php`

الرابط يظهر تلقائيًا في الشريط الجانبي للحسابات التي تملك `MANAGE_USERS` فقط.
